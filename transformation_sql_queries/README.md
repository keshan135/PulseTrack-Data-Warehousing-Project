## SQL Data Cleaning & Transformation

This directory contains SQL queries used to clean, standardize, and prepare raw PulseTrack data for analytical processing.

## Transformations Performed

->TRIM: Removed unnecessary leading and trailing whitespace from text columns.<br>

->Data Type Casting: Converted text-based values into appropriate data types, including dates, timestamps, integers, and numeric values.<br>

->Date & Timestamp Standardization: Converted inconsistent date and timestamp formats into standardized formats.<br>

->Deduplication: Identified and removed duplicate records to maintain data consistency.<br>

->NULL Handling: Handled missing and empty values appropriately.<br>

->Data Cleaning: Standardized raw values to improve data quality and reliability.<br>
